# 엔티켓 회사소개

기존 보라색 디자인과 enticket.kr의 회사소개 구성을 결합한 정적 사이트입니다.

- index.html: 회사소개·사업영역·진행과정·주요 실적·연혁
- design.html / media.html: 브랜드별 소개
- hybrid.css / hybrid.js: 레이아웃·메뉴·문의 동작
- about.js: 사진 및 숫자 애니메이션

문장 줄바꿈은 HTML의 원하는 위치에 <br>을 추가하면 됩니다.
문의 양식은 메일 앱으로 연결되며 서버 접수 기능은 없습니다.
