# 엔티켓 회사소개

- `index.html`: 엔티켓 회사소개 (문장과 줄바꿈 수정)
- `design.html`: 엔디자인 소개
- `media.html`: 엔미디어 소개
- `assets/css/`: 화면 스타일
- `assets/js/`: 메뉴·스크롤·숫자 애니메이션
- `assets/images/`: 사진·로고·모바일 화면
- `assets/icons/`: 서비스와 진행과정 아이콘
- `assets/fonts/`: Pretendard 글꼴

줄바꿈은 원하는 위치에 `<br>`을 넣으면 됩니다.
문의 양식은 메일 앱으로 연결되며 서버 접수 기능은 없습니다.
